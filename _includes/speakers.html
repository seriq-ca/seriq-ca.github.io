{%- comment %} Invited speakers for one event. Call with the basename of a file under _data/speakers/, e.g. {% include speakers.html event="rentree-2026" %}. Shared by both language versions of an event page, so the two cannot drift: the roster and the order are stated once, and each card picks the prose for `page.lang`. Speakers confirm one at a time and their material arrives late, so `title`, `abstract` and `bio` are all optional — a card with none of them is a name, an affiliation and a portrait, which is the honest state of a programme still being built. Cards reuse .member-list wholesale: the wire, the ports and the portrait node are the same component as the committee register on About, and only the speaker's own prose is styled here. `photo` takes either a filename in assets/img/speakers/ or an absolute URL. The members register deliberately dropped its remote branch, but speakers are not ours to ask for a file, so a URL hotlinks their own copy: it can break or change under us, and it tells their host the IP of everyone who loads this page. `referrerpolicy` keeps the referring URL out of that request; nothing keeps the IP out of it. A field that is present but empty counts as absent, so the keys can sit in the data file as a form to fill in. Liquid treats "" as truthy, so a bare `if` on a field would emit an empty element; each value is piped through `strip` — which also turns a missing key into "" — and compared against "" explicitly. Abstracts and bios usually arrive in one language only. Rather than drop the field or silently show French prose as though it were English, the card falls back to whichever language exists and marks it with `lang`, so screen readers and hyphenation treat it correctly. {% endcomment -%} {%- assign t = site.data.i18n[page.lang] -%} {%- assign speakers = site.data.speakers[include.event] -%} {%- assign other_lang = "fr" -%} {%- if page.lang == "fr" %}{% assign other_lang = "en" %}{% endif -%}
